# Acceptance checklist — IngeTrazo 0.5.9

For a clean-machine test:

- Extension appears after restart.
- GO 2D anaStruct panel opens without traceback.
- Check Solver reports anaStruct 1.7.0 OK.
- Built-in Simply Supported Beam solves.
- Cantilever solves DL/LL/WL.
- Portal Frame solves DL/LL/WL and combinations.
- N/V/M/Deflection/Deformed/Reaction can be displayed.
- Load display toggles work.
- Hover readout works without rerunning the solver.
- Load Cases / Combinations table edits persist.
- CSV export completes.
- Selected-case PDF export completes.
- Full PDF export completes.
- Existing plugin is backed up when reinstalling.

This preview is not a substitute for competent engineering review.
